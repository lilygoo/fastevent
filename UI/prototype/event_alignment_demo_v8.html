How to use EventAlign
Choose a workflow. The tutorial will point to the exact control to use at each step.
These are short, guided walkthroughs. They do not overwrite the chart unless you deliberately load or save a study.
Create an event study
6 steps · about 60 seconds
Set the current event, define comparable historical Day 0s, and load the aligned return chart.
  1. Open New study.
  2. Choose the instrument, benchmark, return lens, and window.
  3. Enter the current event and as-of date.
  4. Add named past events and optional milestones.
  5. Load data and read the aligned chart.
Save and reopen a study
5 steps · about 45 seconds
Save the current setup to a source, reopen it from Saved studies, and write later edits back to that same source.
  1. Click Save.
  2. Name the study on its first save.
  3. Open Saved studies.
  4. Use Load to reopen an earlier study.
  5. Click Save after edits to update its source.
